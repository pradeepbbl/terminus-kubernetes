# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Report them privately
through GitHub's "Report a vulnerability" button on the repository's Security
tab (private vulnerability reporting).

Include the chart version, the values you used, and steps to reproduce. You can
expect an initial response within a few days.

## Scope

This repository contains the Helm chart only. Vulnerabilities in the Terminus
application itself should be reported to that project.
